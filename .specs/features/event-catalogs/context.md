# Decisões do usuário: catálogos e evento

| Pergunta | Decisão |
|---|---|
| Formatos selecionáveis no evento | **Todos** os formatos do catálogo (ver R-001) |
| Datas | Só o dia (início e fim) |
| Local | Nome do local (obrigatório) + cidade + UF (opcionais) |
| Categorias | O admin gerencia (criar, renomear, desativar) nos 3 catálogos |

Do enunciado: o evento tem descrição, início e fim, tipo, formato, modalidade, local e formato de participação (individual, dupla, equipe). Regras de competição ficam para depois.
Adicionado por necessidade: **nome do evento** (obrigatório), organização dona e criador.
